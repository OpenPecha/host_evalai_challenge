Submission Guidelines: Please adhere to the following guidelines for submitting your results:

1. Submissions must be in the JSON format. Ensure the file structure and key-value pairs strictly follow the format outlined in the challenge instructions.

2. The submission JSON file should include all keys specified in the ground truth JSON file. Missing keys will result in validation errors.

3. Each key in the submission file must have a corresponding string value. Non-string values (e.g., numbers, lists, or null) will lead to rejection.

4. Use the same key names as provided in the ground truth file. Key mismatches or typos will invalidate the submission.

5. Avoid submitting empty strings or placeholders. The content of each value must represent the predicted output for the corresponding key.

6. Ensure the JSON file is properly formatted (e.g., no syntax errors or unclosed brackets). Malformed files will not be accepted.

8. Validate your submission locally before uploading to ensure compliance with the format requirements. Tools like JSON validators or format checkers can be used.

9. Submissions will be evaluated on metrics such as Word Error Rate (WER) and Character Error Rate (CER). Please refer to the evaluation section for details.

Any submissions that do not comply with these guidelines may be rejected or disqualified by the challenge organizers.
